# Fixed PBS certificate artwork

`pbs-certificate-blueprint.jpg` is the cleaned background for the approved light powder-blue reference, normalized to 2048 × 1536, retaining its brand, border, MEP drawing, grid, gold seal and fixed lettering. Sample recipient details, preview identifiers, dates, assessment values, signatory captions and footer placeholders were removed before the image was flattened. Never substitute the original populated screenshot here.

The shared renderer overlays real record details and two genuine administrator-supplied signatures. Static appearance is intentionally locked; older logo, stamp, theme and colour settings do not change this certificate. Original uploaded signature PNGs remain stored without modification; a navy-ink rendering copy is used on the pale blue paper. The gold seal retains its approved blue interior.

PDF geometry is 280 × 210 mm (4:3), independent of viewport size. Other administrative documents retain their own page sizes. Instrument Sans is embedded from the included SIL-licensed font files for dynamic text.
