# Fixed PBS certificate artwork

`pbs-certificate-blueprint.jpg` is the cleaned background for the approved 2048 × 1536 reference, retaining its brand, border, MEP drawing, grid, gold seal and fixed lettering. Sample recipient details, credential identifiers, dates, handwritten signatures and QR were removed before the image was flattened. Never substitute the original populated screenshot here.

The shared renderer overlays real record details and two genuine administrator-supplied signatures. Static appearance is intentionally locked; older logo, stamp, theme and colour settings do not change this certificate. Original uploaded signature PNGs remain stored without modification; a light-ink rendering copy is used on the navy paper.

PDF geometry is 280 × 210 mm (4:3), independent of viewport size. Other administrative documents retain their own page sizes. Instrument Sans is embedded from the included SIL-licensed font files for dynamic text.
